Methodology

The assistant loads Word, Excel, and PowerPoint files into source-aware chunks, filters and deduplicates those chunks, extracts candidate metrics using rules and the configured LLM mode, then compares overlapping numeric values using deterministic Python.

The LLM is used only for candidate extraction. It is not used to decide whether two figures conflict or which source should be treated as authoritative.

Limitations

  • The report depends on the quality and coverage of the supplied source files.
  • Rule-based extraction only captures clear metric/value patterns.
  • Source reliability scores are simple heuristics and should be reviewed before operational use.
  • Official publication status should be confirmed before figures are quoted externally.

Recommended Next Steps

  • Review high severity discrepancies before using figures in external briefings.
  • Check caveated records against the original source documents.
  • Confirm authoritative sources for metrics that appear in multiple files.
  • Retain preliminary estimates as historical context when revised figures are available.
